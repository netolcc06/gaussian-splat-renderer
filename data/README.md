# data/

Test scenes for the renderer. All files are in the standard INRIA 3DGS PLY format
(binary little endian, float32, see `docs/notes/ply-format.md`). Inspect any file with:

```
python -I tools/ply_info.py data/scenes/train_7k/point_cloud.ply
```

`scenes/` is git-ignored (large, third-party licensed). Re-download with the URLs below.
Downloaded files are treated as untrusted data: only parsed, never executed
(`cfg_args` is a Python repr — read it as text, never `eval` it).

## Real scenes (`data/scenes/`)

| Dir | Content | Gaussians | SH deg | Size | Extras |
|---|---|---|---|---|---|
| `utsuho_plush/` | single object (plush toy), user capture | 53,671 | 3 | 13.3 MB | normals named `nxx ny nz` (non-standard name!) |

All three: 62 float properties/gaussian (248 bytes), file size matches header exactly.

### Sources

- **utsuho_plush** — `Utsuho Plush/utsuho_plush.ply` from
  https://huggingface.co/datasets/solaaaa/sample-gaussian-splats
  (direct: https://huggingface.co/datasets/solaaaa/sample-gaussian-splats/resolve/main/Utsuho%20Plush/utsuho_plush.ply).
  License: **none stated** in the repo (readme: "Processed using ~150 photos, Plush by monomo";
  the plush is a third-party character design). Use for local testing only; do not redistribute.
- **train_7k** — `train/point_cloud/iteration_7000/point_cloud.ply` (+ `cameras.json`, `cfg_args`) from
  https://huggingface.co/johnowhitaker/gaussian_splatter_models, a per-scene mirror of the
  official INRIA pretrained `models.zip` (https://github.com/graphdeco-inria/gaussian-splatting,
  "Pre-trained models"). `cfg_args` confirms the INRIA run (`eval=True, sh_degree=3`, source
  `tandt/train`).
- **bonsai_30k** — `bonsai/point_cloud/iteration_30000/point_cloud.ply` (+ `cameras.json`,
  `cfg_args`) from the same mirror. `cfg_args`: `images='images_2'`, `eval=True, sh_degree=3`,
  source `360_v2/bonsai`.

### License caveats

- INRIA pretrained models are outputs of the 3DGS code, which is under the
  **Gaussian-Splatting License** (non-commercial research/evaluation use only):
  https://github.com/graphdeco-inria/gaussian-splatting/blob/main/LICENSE.md
  The mirror repo itself states no license.
- The underlying captures belong to their datasets: Tanks and Temples
  (https://www.tanksandtemples.org/license/) and Mip-NeRF 360
  (https://jonbarron.info/mipnerf360/). Check their terms before any redistribution.
- Keep all of `scenes/` out of git and out of any published artifact.

### Other candidates (not downloaded)

The same mirror has all 13 INRIA scenes at 7k and 30k (e.g. `train` 30k 255 MB,
`counter` 30k 303 MB, `garden` 30k 1.45 GB, `bicycle` 30k 1.52 GB) — useful for stress
tests later. `datasets/Voxel51/gaussian_splatting` (Apache-2.0 card) has train/truck/
playroom/drjohnson. Many Hugging Face "splat" repos only host `.splat`/`.ksplat` files,
which are not PLY.

## Synthetic scenes (`data/synthetic/`)

Generated by `python -I tools/gen_synthetic_ply.py --all` (deterministic, seed 1234).
All objects live within ~[-2.5, 2.5]³ around the origin; a camera ~6-8 units away
looking at the origin frames them. Values are stored pre-activation like real files
(logit opacity, log scale, unnormalized w-first quaternions in some patterns).

| File | Gaussians | SH deg | Purpose |
|---|---|---|---|
| `single_sh0.ply`, `single_sh3.ply` | 1 | 0 / 3 | isotropic σ=0.5, α=0.8, orange, at origin; minimal smoke test |
| `grid_512_sh0.ply`, `grid_512_sh3.ply` | 512 (8³) | 0 / 3 | anisotropic (8:2:1) splats, colour = position, varied rotations; sh3 adds an x-lobe on one channel per splat |
| `random_10000_sh1.ply` | 10,000 | 1 | random cloud in r=2 sphere, unnormalized quats, random SH |
| `random_100000_sh3.ply` | 100,000 | 3 | same, larger (24.8 MB, git-ignored; regenerate) |
| `random_2000_sh2_nonormals.ply` | 2,000 | 2 | variant without `nx ny nz` |
| `overlap_sh0.ply` | 4 | 0 | R (z=-1.5), G, B, white (z=+1.5), α=0.5, partial overlap; quats scaled ×2; blending-order test (camera on +z sees white in front) |
| `shdir_sh3.ply` | 6 | 3 | grey DC + a single SH basis (k=1,2,3,4,6,9: +red / -blue) per splat on a ring; tests SH direction convention |
